# C++ Image Editor

A C++ image editor developed as a 3-member team project for the Object-Oriented Programming course at the Faculty of Computers and Artificial Intelligence, Cairo University.

The project provides a collection of image-processing filters that can be applied to image files through direct pixel-level RGB manipulation.

## Features

The image editor includes 20 image-processing filter categories:

1. Grayscale Conversion
2. Black & White
3. Invert
4. Merge Images
5. Flip
6. Rotate
7. Darken & Lighten
8. Crop
9. Add Frame
10. Detect Image Edges
11. Resize
12. Blur
13. Sun Ray
14. Oil Painting
15. TV Screen
16. Purple Effect
17. Infrared
18. Skewing
19. Saturation — Manual & Automatic
20. Contrast — Manual & Automatic

## Technologies

* C++
* Image Processing
* RGB Pixel Manipulation
